–
กรอกวันเปิดสาขาเพื่อคำนวณวันติดตั้ง/รื้อถอนอัตโนมัติ auto
2

แบ่งโซนประชาสัมพันธ์

ไม่ต้องกรอก — แค่แปะรูปในไฟล์ PPT ทีหลัง
สไลด์นี้ในไฟล์ PPT จะมีแค่หัวข้อ "2. แบ่งโซนประชาสัมพันธ์" กับกรอบว่างให้แปะภาพแผนที่แบ่งโซนจาก SA เอง — ไม่ต้องกรอกอะไรในเครื่องมือนี้
3

แผนงานประชาสัมพันธ์ก่อนเปิดสาขา

Template คงที่ auto
กรอกจุดติดป้าย (Step 5) เพื่อให้ระบบเติมจำนวนป้ายในแผนอัตโนมัติ
4

ตารางแผนงานประชาสัมพันธ์รายวัน

5

จุดติดป้าย

6

กิจกรรมหน้าร้าน + ขอความช่วยเหลือ

แนบรูปผังงาน แล้วปักจุดสัญลักษณ์ (จุดกลม/ดาว/หัวใจ/สี่เหลี่ยม/สามเหลี่ยม สีใดก็ได้) พร้อมพิมพ์อธิบายความหมายแต่ละจุด — จะรวมกับ "รายละเอียดกิจกรรม" และ "ขอความช่วยเหลือ" ในสไลด์เดียวกันตอนสร้าง PPT
7

โรงแรม / ที่พัก

สรุปสำหรับ MKT + จัดซื้อ

รวมป้ายอัตโนมัติจาก Step 5
วาง JSON ที่เคย Export ไว้ก่อนหน้า (เก็บไว้ใน Notes/ไลน์ส่งตัวเอง ฯลฯ) เพื่อดึงข้อมูลกลับมาทำต่อ — ใช้ได้เสมอไม่ว่าจะเปิดเครื่องมือนี้ผ่านที่ไหนก็ตาม

JSON สำหรับส่งให้ AI สร้างไฟล์ PPT

คัดลอกทั้งหมดนี้ ไปวางในแชทกับ Claude พร้อมบอกว่า "สร้าง Pack GO PPT จากข้อมูลนี้" — Claude จะสร้างไฟล์ .pptx จริงให้ (เว้นช่องแนบรูปที่ถ่ายมาเอง) — แนะนำให้เก็บ JSON นี้ไว้ที่อื่นด้วย (Notes/ไลน์ส่งตัวเอง) เผื่อใช้ปุ่ม Import JSON กลับมาทำต่อทีหลัง
